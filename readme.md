# StyleHub Welcome Campaign - Email Developer Portfolio Project

## Overview
A responsive HTML Email Template built with AMPscript dynamic personalization and SQL audience segmentation logic.

## Key Features
- **Responsive Design:** Fluid table structure supporting desktop and mobile devices.
- **Outlook Compatibility:** Includes MSO conditional tags (`<!--[if mso]>`) and VML buttons for Microsoft Outlook rendering.
- **Dynamic Personalization:** Built-in AMPscript to dynamically render subscriber first name with fallback handling.
- **Audience Targeting (SQL):** Query designed to segment new active subscribers who haven't made a purchase yet.

## Standard Operating Procedure (SOP) Checklist
- [x] Responsive layout testing across mobile & desktop viewports.
- [x] AMPscript validation with fallback for missing subscriber attributes.
- [x] Outlook rendering fixes implemented using VML shapes.
- [x] Deliverability compliance check (Alt tags, Unsubscribe link).
